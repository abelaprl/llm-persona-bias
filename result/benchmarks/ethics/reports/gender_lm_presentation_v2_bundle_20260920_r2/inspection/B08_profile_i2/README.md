# B08_profile_i2_overall

Marker candidate · profil seluruh penjelasan tersedia; bukan pasangan.
N = netral; E = eksplisit; I1–I3 = tiga narasi implisit.
NA: 0; simbol × di kolom NA, bukan nol. Jumlah mentah: CSV.

Scope: `overall`.

Kolom sumber dipertahankan; grafik hanya memakai kolom display. Jumlah mentah `raw_count_total` dan denominator seluruh persona tersedia di [marker_context.csv](marker_context.csv).
