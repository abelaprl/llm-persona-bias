# Visual kandidat Bab VI — Gender ETHICS linguistic marker

Paket ini hanya memperbaiki lapisan presentasi. Statistik, pasangan, kamus, dan p-value berasal dari bundle frozen v2.0.1 r3. Arah sumber Woman−Man dibalik secara eksplisit menjadi Man−Woman agar konsisten dengan Gender GSM8K.

Gambar 00 adalah pemeriksaan cakupan. Gambar 01–04 adalah hasil langsung utama. Gambar hanya PNG (300 dpi), dengan CSV untuk angka. Semua titik berwarna penuh; segitiga menandai p Holm < 0,05 dan lingkaran menandai hasil lainnya. Density memakai matched rank-biserial tanpa memasangkan CI mean density pada rank. Marker biner memakai selisih prevalensi dan CI 95% marginal. Seluruh hasil masih candidate sampai audit manusia independen selesai.
