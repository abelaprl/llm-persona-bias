# Arsip notebook Religion

Folder ini menyimpan notebook, gambar, dan keluaran historis yang sebelumnya
bercampur dengan artefak aktif di `notebooks/religion/`.

Struktur arsip:

- `root/legacy_notebooks/`: notebook lama yang dahulu berada langsung di root.
- `root/_arsip/`: arsip umum dari root lama.
- `root/img/`: aset gambar historis.
- `gsm8k_accuracy/`: arsip analisis akurasi GSM8K.
- `ethics_accuracy/`: versi lama, keluaran per subset, dan arsip analisis akurasi ETHICS.
- `linguistic_marker/ETHICS/`: versi historis analisis linguistic marker ETHICS.
- `linguistic_marker/GSM8K/`: versi historis analisis linguistic marker GSM8K.

Artefak yang sedang dipakai tetap berada di `notebooks/religion/`. Pemindahan
ini hanya merapikan lokasi; data arsip tidak dihapus.
