# ETHICS Gender — Justice

Folder ini menyimpan rincian subset `justice`.

- `condition_summary.csv`: status dan metrik per model × persona.
- `abstain_reason.csv`: penyebab abstain dengan denominator sumber.
- `paired_effects.csv`: hasil paired dari bundle sumber.
- `figures/`: visual detail subset.

Visual utama ETHICS Gender berada satu tingkat di atas, pada folder `ethics accuracy analysis`.
