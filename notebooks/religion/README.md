Notebook memuat 19 sel kode dan 78 grafik dengan output tersimpan. Bagian 5B menampilkan 20 marker agama lengkap, 5C memuat kartu N/E/implicit pada soal sama, dan 5D menunjukkan jumlah kategori marker berbeda per respons. Kartu bersifat purposif; label fungsi tetap kandidat. Keragaman kategori bergantung pada kamus dan panjang respons, bukan ukuran menyeluruh kekayaan bahasa. Menjalankan seluruh sel memuat gambar dan tabel hasil beku; tidak memanggil API atau menghitung ulang scoring.

Gambar menggunakan lebar cetak 16 cm, DejaVu Sans minimal 8,5 pt, dan PNG 300 dpi. Panel padat dipecah menjadi beberapa halaman dengan angka yang tetap sama. Versi sebelum perbaikan cetak disimpan di [arsip](<../../archive/notebooks/religion/linguistic_marker/ETHICS/archive/before_print_20260919_r2/>).

59 marker mencakup delapan keluarga. Semua marker masih candidate; anotasi dua reviewer dan precision/recall empiris belum tersedia. Baca denominator, status CI dan gap pada laporan sebelum menarik kesimpulan.
